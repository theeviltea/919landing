# 919 landing

Marketing site for the 919 app — EN at `/`, RU at `/ru/`. Astro, static output, no client framework.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
```

- Copy: `src/i18n.ts` (both languages, store and social links).
- Page: `src/components/Landing.astro`; styles: `src/styles/global.css`.
- App screenshots: `public/screens/` (captured from the 919 app prototype), people: `public/people/`.
